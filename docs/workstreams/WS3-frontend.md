## Stack and conventions

- `npx create-next-app@latest frontend --ts --tailwind --eslint --app --src-dir --import-alias "@/*"`
- shadcn/ui (button, card, badge, table, dialog, select, checkbox, textarea, toast/sonner, tooltip, tabs), lucide-react icons, TanStack Query, `openapi-typescript` (types from backend), `@elevenlabs/react` (browser calls), date-fns.
- `src/lib/api.ts`: `apiFetch(path, init)` adds base URL `NEXT_PUBLIC_API_BASE_URL` and `X-BV-User` / `X-BV-Role` from the role store; throws typed errors from `{"error":{...}}`.
- `src/lib/api-types.ts`: generated by `make types`. Never hand-edit.
- Query keys: `["checkin", id]`, `["checkins", date]`, `["escalations", status]`, `["drafts", filters]`, `["sae", id]`, `["sponsor-inbox"]`, `["eval"]`.
- Polling: live check-in 1000 ms while status is `dialing` or `in_progress`, then 5000 ms for 30 s; escalation banner 2000 ms; everything else on focus.
