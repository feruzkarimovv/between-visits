# Corrective and preventive actions (CAPA)

Defects that reached a demo, export or report, with the fix and the automated test that keeps each one from coming back. Each prevention test is linked to a requirement in `validation/requirements.yaml` and runs in `make test` and `make validate ARGS=--check`. The commit column gives the commit message prefix, which stays stable when commits are rebased or cherry-picked (`git log --grep '^<prefix>'`).
